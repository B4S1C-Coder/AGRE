# AGRE
Agent Guardrail & Runtime Engine is a minimal gateway that sits between the LLM and the external world, allowing you to enforce policies and permissions specific to your LLM Deployment.

This is the _"boring layer"_ that sits between the LLM and the world, which warns you to consult a doctor when you ask the LLM for medical advice or which stops your LLM from inadverntantly writing malware or telling you how to make a nuclear bomb!
